# 前端面试刷题器

一个单文件、零依赖、可离线使用的前端面试刷题工具。点按钮随机出新题，先自己想，再看提示和答案。

**共 85 题**，覆盖 JS 基础、CSS、浏览器与网络、Vue/React、工程化、算法手写、概念理解七类，难度分基础 / 高频 / 进阶三档。

## 怎么用

直接双击 `interview-trainer.html`，用浏览器打开即可。不需要 Node、不需要 npm、不需要构建，断网也能用。

### 快捷键

| 按键 | 作用 |
|---|---|
| `空格` 或 `→` | 换一题 |
| `H` | 看提示 |
| `A` | 看答案 / 收起答案 |
| `S` | 收藏 / 取消收藏 |

### 筛选

- **分类**：七类可任选
- **难度**：基础 / 高频 / 进阶
- **范围**：随机全部 / 只出没看过的 / 只看我的收藏

进度与收藏保存在浏览器 localStorage，刷新不丢。右上角可切换深浅色主题，或重置进度。

## 目录结构

```
interview-trainer.html          主程序：样式、逻辑、题库全部在这一个文件里
scripts/check-bank.js           题库校验脚本（零依赖）
.github/workflows/check-bank.yml  CI：每次 push 自动跑校验
```

## 怎么加题

打开 `interview-trainer.html`，找到 `const BANK = [`，按同样格式往数组里追加对象：

```js
{c:'js', lv:'高频',
 q:'题干写在这里',
 h:'提示写在这里',
 a:`<p>答案支持 HTML：<b>加粗</b>、<code>行内代码</code></p>
<pre><code>代码块直接写在 pre 里</code></pre>`},
```

字段说明：

| 字段 | 含义 | 合法值 |
|---|---|---|
| `c` | 分类 | `js` `css` `net` `fw` `eng` `algo` `concept` |
| `lv` | 难度 | `基础` `高频` `进阶` |
| `q` | 题干 | 任意文本，**必须全局唯一** |
| `h` | 提示 | 只给思考方向，别把答案写进去 |
| `a` | 参考答案 | HTML 字符串 |

### 两条硬性约束

1. **题干必须全局唯一。** 题干是收藏与进度的稳定键（代码里的 `keyOf`），重复会导致记录错位，校验脚本会直接报错。
2. **答案的反引号内不能出现裸反引号。** 答案本身用模板字符串包裹，行内代码一律用 `<code>` 标签——否则模板字符串会提前终止，整个页面白屏。这是本项目真实踩过的坑。

## 校验

改完题库后跑一次：

```bash
node scripts/check-bank.js
```

脚本会做两件事：

1. 编译页面里的整段脚本，抓语法错误（上面第 2 条约束就是靠这一步拦住的）
2. 解析题库，校验字段完整性、分类与难度合法性、题干唯一性

有错误时退出码为 1，所以也能直接用于 CI。仓库已配置 GitHub Actions，push 后会自动运行。

也可以指定文件路径，用于校验校验器本身是否真的能拦住错误写法：

```bash
node scripts/check-bank.js ./某个改动过的副本.html
```

## 技术说明

- **为什么是单文件**：直接用 `file://` 打开时，浏览器会拦住外部 JS 模块的加载（跨域限制）。单文件是零依赖离线可用的最简方案。
- **持久化键为什么不用数组下标**：早期版本用下标做 id，在题目中间插入新题会让后面所有题的 id 后移，已存的收藏就会指向别的题。现在改用 `分类::题干` 作为稳定键。
- **旧数据迁移**：如果浏览器里存在旧版（v1，按下标存储）记录，首次打开新版本时会自动换算成稳定键，无需手动处理。
- **修改题干等于换钥匙**：改动某题题干会让该题的进度和收藏重置，这是预期行为。
